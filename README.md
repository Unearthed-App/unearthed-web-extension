# Unearthed Browser Extension

> **Wait**: there is an alternative way to sync with Unearthed and that is through **[Unearthed Local](https://unearthed.app/local)** which is an app that you install on your device, where there is no cloud required. Once you have it you can keep it forever. For the Unearthed Local app, you do **not** need to use this browser extension.

Seamlessly sync your Kindle highlights and notes to your favorite platforms through the Unearthed ecosystem. This browser extension is the bridge that connects your Amazon Kindle library to [Unearthed.app](https://unearthed.app), enabling automatic synchronization of all your reading highlights and notes.


## What is Unearthed?

Unearthed is a comprehensive reading ecosystem that helps you capture, organise, and connect your reading insights across multiple platforms. The ecosystem includes:

- **[Unearthed Local](https://unearthed.app/local)** - Self-hosted desktop application (no subscription)
- **Unearthed Online** ([unearthed.app](https://unearthed.app)) - Cloud-based service with AI-powered (opt in) features
- **Browser Extension** (this extension) - Allows for auto sync
- **Obsidian Plugin** - Syncs to your Obsidian vault
- **KOReader Plugin** - Syncs highlights from KOReader devices and merges them

## Features

### Kindle/KOReader Integration

- **Complete Sync**: Automatically syncs all highlights and notes from your Amazon Kindle Notebook
- **Smart Updates**: Only syncs new highlights, avoiding duplicates
- **Book Merging**: Combines highlights from the same book across different sources (Kindle + KOReader)

### Platform Connectivity

Once your Kindle data is in Unearthed, you can sync it to:

- **Obsidian**
- **Notion**
- **Capacities**
- **Supernotes**

### Advanced Features (Unearthed Online)

- **Daily Reflections** - Receive curated highlights via email or in your daily notes
- **Read analysis** - Automatically extract themes, ideas, blind spots from your highlights
- **Interactive Graph View** - Visualize connections between books, highlights, and tags
- **Custom Templates** - Format how books and highlights appear in your target platforms
- **Tag Management** - Manually or automatically tag highlights to connect ideas

## How It Works ('Unearthed Online' specific)

1. **Install the Extension**: Add this browser extension to Chrome or Firefox
2. **Connect to Unearthed**: Create an account at [unearthed.app](https://unearthed.app) and generate an API key
3. **Sync Kindle Data**: The extension reads your Amazon Kindle Notebook and sends highlights to Unearthed
4. **Connect Other Platforms**
5. **Enjoy Unified Access**: All your reading insights are now available across your entire workflow

## Installation

### Prerequisites

- Active Amazon Kindle account with highlights in your [Kindle Notebook](https://read.amazon.com/notebook)
- Unearthed account [unearthed.app](https://unearthed.app)

### Setup Steps

1. **Install the Extension**:

   - [Chrome Web Store](https://chromewebstore.google.com/detail/unearthed-app/aneeklbnnklhdaipicoakebmbedcgmfb)
   - [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/unearthed-app/)

2. **Create Unearthed Account**: Sign up at [unearthed.app](https://unearthed.app)

3. **Generate API Key**: In your Unearthed settings, create an API key for the browser extension

4. **Configure Extension**: Enter your API key and User ID in the extension settings

## Integration with Other Unearthed Tools

### Obsidian Integration

After syncing Kindle data to Unearthed, install the [Unearthed Obsidian Plugin](https://github.com/Unearthed-App/unearthed-obsidian) to:

- Create formatted book notes in your vault
- Receive daily reflections in your daily notes
- Use custom templates for consistent formatting
- Link tags and highlights across your knowledge base

### KOReader Integration

If you use KOReader devices, install the [Unearthed KOReader Plugin](https://github.com/Unearthed-App/unearthed-koreader) to:

- Sync highlights from e-ink devices
- Merge KOReader and Kindle highlights for the same books
- Enable wireless syncing without USB connections
